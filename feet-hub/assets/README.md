# assets/ — médias du site

## Fond vidéo du hero : `hero.mp4`
Le hero de `index.html` joue automatiquement `assets/hero.mp4` en fond (avec repli sur
une image si le fichier est absent — rien ne casse).

### Comment l'ajouter (1 min)
1. Télécharge un clip **libre de droits** (usage commercial), par exemple :
   - Mixkit — pieds dans l'océan : https://assets.mixkit.co/videos/2057/2057-1080.mp4
   - Mixkit — pieds sur la plage : https://assets.mixkit.co/videos/1013/1013-1080.mp4
   - Pexels : https://www.pexels.com/video/the-feet-of-a-person-in-the-water-20549084/
2. Renomme-le **`hero.mp4`** et place-le dans ce dossier `feet-hub/assets/`.
3. Recharge `index.html` → la vidéo joue en fond.

> ⚠️ Médias **d'ambiance** uniquement (tasteful, non explicites). Les licences gratuites
> interdisent l'usage explicite/fétichiste. Voir `../IMAGES_ET_CONTENU.md`.
