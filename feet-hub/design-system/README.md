# SOLEA — Design System (pour Claude Design)

Composants de référence de la marque SOLEA, au format que **Claude Design** lit
(chaque fichier commence par `<!-- @dsCard group="…" name="…" -->`).

## Contenu
| Fichier | Groupe | Ce qu'il montre |
|---|---|---|
| `colors.html` | Foundations | La palette (noir-prune, rose, or rosé, crème…) |
| `typography.html` | Foundations | Playfair Display (titres) + Inter (texte) + dégradé |
| `buttons.html` | Components | Boutons rose / ghost (2 tailles) |
| `cards.html` | Components | Carte catégorie + carte créateur |
| `logo-badges.html` | Brand | Logo SOLEA, tagline, badge 18+, pastilles |

## Comment l'utiliser avec Claude Design
1. Ouvre **claude.ai/design** (ou la barre latérale de l'app desktop Claude).
2. **Importe ton design system** depuis le repo GitHub `chaima0007/TEST`
   (dossier `feet-hub/design-system/`), ou uploade ce dossier.
3. Claude Design reconnaît la charte → tes nouveaux visuels sortent **on-brand**
   (mêmes couleurs, mêmes polices, même style).
4. Quand un visuel est prêt → **Send to Claude Code Web** pour me le renvoyer ici,
   et je l'intègre au site.

> Charte complète en texte : `../BRAND_KIT.md`.
> ⚠️ Reste tasteful / non explicite (Claude Design refuse l'explicite). 18+.
