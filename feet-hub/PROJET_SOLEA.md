# SOLEA — Projet finalisé ✅

Hub de découverte bilingue (FR/EN), 18+, pour amateurs de contenu « pieds ».
**Modèle légal** : aucun contenu hébergé — on référence des créateurs et on renvoie via
liens d'**affiliation** (+ pub + newsletter). Site **statique**, déployable partout, gratuit.

## 🗂️ Les pages (toutes faites)
| Page | Rôle |
|---|---|
| `index.html` | Accueil bilingue, intro cinématique, hero (image/vidéo de fond), catégories, créateurs, newsletter, bannière Empreinte |
| `explorer.html` | Explorateur — **des centaines de catégories**, compose ta sélection |
| `category.html` | Pages de catégorie dédiées + **abonnement par catégorie** |
| `diapason.html` | Quiz d'ambiance → pré-remplit l'Explorateur + forge l'**Empreinte** |
| `empreinte.html` | **Carte de goût partageable** (PNG) — moteur viral SFW |
| `collections.html` | **Collections numérotées** hebdo (curation datée) |
| `creators.html` | Onboarding **créatrices** (affiliation, sans hébergement) |
| `aide.html` | **Assistance 24/7** (assistant Q/R + contact) |
| `logo.svg` | Logo + favicon |

## ✅ Ce qui est FAIT
- Site complet, bilingue, design « luxe sombre », intro ciné, logo, médias d'ambiance.
- Fonctions uniques : Explorateur, Diapason, Empreinte partageable, Collections.
- Assistance 24/7, pages reliées entre elles, age-gate 18+ partout.
- Affiliation câblée (cartes & catégories), SEO de base (sitemap, robots, OG), déploiement prêt.
- Toute la stratégie documentée.

## ⏳ Ce qu'il te RESTE (toi seul peux le faire)
1. **Mettre ton code d'affiliation** : remplace `SOLEA_CODE` par ton vrai code FeetFinder
   (rechercher-remplacer dans les fichiers `.html`). → sans ça, 0 €.
2. **Ajouter des créateurs** : voir `GUIDE_CONTENU.md` (où les trouver + où les coller).
3. **(option) Déposer `assets/hero.mp4`** : voir `assets/README.md`.
4. **Mettre en ligne** quand tu veux : voir `LANCEMENT.md` / `DEPLOIEMENT.md` (Netlify/Cloudflare).
5. **Trafic** : suivre `STRATEGIE_MARKETING.md` + `guides/RECHERCHE_AUDIENCE.md`.

## ⚖️ Lignes rouges (à ne jamais franchir)
Pas de contenu explicite hébergé · pas de personnes non consentantes / **célébrités** ·
pas de médias volés · 18+ obligatoire · revenus déclarés (auto-entrepreneur).
