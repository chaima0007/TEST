# candidates/ — fiches candidates (§7)

Un fichier par candidat : `AAAA-MM-JJ-nom-du-candidat.md`.
Une dépendance n'entre dans `package.json` qu'après une fiche VALIDÉE ici.

```
ID / Source / Besoin couvert / Licence (verdict Guardian) / Sécurité (verdict Sentinel,
comportemental Zone 1) / Extrait illustratif (quelques lignes max, avec "voir source : URL")
/ Objection Contradicteur / Argument Avocat / Statut (REJETÉ / VALIDÉ NON INTÉGRÉ /
INTÉGRÉ) / Date
```

Rappel §0 : installer une bibliothèque validée est **normal et encouragé**. Ce qui reste
restreint, c'est le copier-coller manuel de code source hors système de dépendances.
