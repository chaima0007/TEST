# Lexique des sigles — projet ATLAS

Ce document donne le SEUL sens autorisé de chaque sigle. Si un sigle n'est pas dans cette liste, la bonne réponse est : « Ce sigle n'est pas défini dans mes documents. »

- RAG = Retrieval-Augmented Generation (génération augmentée par récupération). L'IA cherche d'abord dans les documents de Chaima, puis répond en les citant.
- LLM = Large Language Model (grand modèle de langage). Le moteur qui produit le texte ; ici qwen2.5:3b via Ollama.
- Ollama = le logiciel qui fait tourner le modèle localement sur la machine, sur l'adresse 127.0.0.1, port 11434.
- AnythingLLM = le logiciel de bureau qui gère les documents, le RAG et le chat, branché sur Ollama.
- ATLAS = le nom du projet d'IA locale, privée et souveraine de Chaima. Ce n'est pas un sigle : il ne se développe pas.
- Zone 1 = quarantaine : un logiciel candidat est testé sous surveillance réseau avant d'être accepté.
- Zone 3 = activation contrôlée : le logiciel est accepté et utilisé, après accord explicite de Chaima.
- TCPView = outil Microsoft qui montre quel programme parle au réseau, et vers où.
- Peppol = réseau européen de facturation électronique, obligatoire en Belgique depuis le 1er janvier 2026.
- D-001 = décision numéro 1 en attente : geler les nouveaux projets jusqu'au premier message d'un prospect.
- A-DECIDER = le fichier qui liste tout ce qui attend une décision de Chaima.
- CI = intégration continue : vérification automatique du code avant fusion.
- tokens/s = vitesse de génération du modèle, en jetons de texte par seconde.
- LLAM = « La Loi Avec Moi », un projet de Chaima. Ce n'est pas un sigle technique.
- CODEX = le protocole de gouvernance de l'Empire de Chaima (rôles, zones, parcours, vocabulaire).
