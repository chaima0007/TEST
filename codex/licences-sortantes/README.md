# /codex/licences-sortantes/ — LICENCES SORTANTES (§11)

Contrats de licence à revendre/louer, RÉDIGÉS EN ENTIER (pas une idée de contrat). Bloqué uniquement :
l'envoi à un client réel et la signature (§10). Format §7 :
ID / Composant / Modèle envisagé / Document créé / Vérifications avant usage réel / Statut : PROPOSÉ ET RÉDIGÉ.
