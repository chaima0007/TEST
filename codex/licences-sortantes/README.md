# licences-sortantes/ — notre PI à nous (§11)

Un fichier par composant licenciable : `AAAA-MM-JJ-composant.md`.
L'agent **rédige le document complet** (contrat, prix, conditions) — pas juste une idée.

```
ID / Composant / Modèle envisagé / Document créé (contrat complet rédigé) /
Vérifications avant usage réel / Statut : PROPOSÉ ET RÉDIGÉ
```

**Bloqué, sans exception :** l'envoi à un client réel et la signature (§10).
Relecture juridique humaine obligatoire avant tout usage.

**Brevets :** recherche préliminaire d'antériorité uniquement. Jamais de rédaction de
revendications, jamais de dépôt. Le logiciel pur n'est généralement pas brevetable en
Europe (art. 52(2)(c) CBE) — conseil en brevets humain obligatoire.
