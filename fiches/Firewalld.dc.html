Pare-feu firewalld

Une phrase à retenir : je choisis d'abord la zone, puis ce que j'autorise, puis si le changement est temporaire ou permanent.

Runtime et permanent — la notion centrale

Runtime — en mémoire
sudo firewall-cmd --add-service=http → effet immédiat, perdu au --reload → filet de sécurité : une règle qui te bloque disparaît d'elle-même
Permanent — sur le disque
sudo firewall-cmd --permanent \ --add-service=http sudo firewall-cmd --reload → écrit, mais actif seulement après le --reload

Sens des deux commandes : --runtime-to-permanent copie la mémoire vers le disque (j'ai testé, j'enregistre) · --reload copie le disque vers la mémoire (et écrase ce qui n'a pas été enregistré).

Les commandes, par question posée

Ce que je veux savoir ou faire
Commande
Le pare-feu tourne-t-il ?
firewall-cmd --state
Toute la configuration de la zone
firewall-cmd --list-all
Zone par défaut · zones actives
firewall-cmd --get-default-zone

Toutes les zones · changer la zone par défaut
firewall-cmd --get-zones
firewall-cmd --set-default-zone=work
Déplacer une interface
firewall-cmd --zone=public --change-interface=ens18
Ouvrir un port
firewall-cmd --zone=public --add-port=9001/tcp
Autoriser un service connu
firewall-cmd --zone=public --add-service=http
Enregistrer tout ce que j'ai testé
firewall-cmd --runtime-to-permanent

L'exception : créer une zone

sudo firewall-cmd --permanent --new-zone=lodhi # --permanent obligatoire sudo firewall-cmd --reload # la charge en runtime sudo firewall-cmd --zone=lodhi --add-service=ssh

Sans --permanent : Option can be used only with --permanent.

Les pièges qui coûtent des points
  • --reload efface les règles runtime non enregistrées. Enregistre avant de recharger.
  • Retirer ssh ne coupe pas ta session en cours : firewalld laisse vivre les connexions établies. C'est la prochaine connexion qui sera refusée — et tu ne t'en aperçois qu'une fois dehors.
  • --add-port=9001 sans /tcp est refusé, et autoriser un service ne le démarre pas : le pare-feu laisse passer, systemctl démarre.
  • Le service tourne, le port écoute, le pare-feu est ouvert, et ça ne passe toujours pas ? Quatrième gardien sur Rocky : getenforce → SELinux.
