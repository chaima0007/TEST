Disques, montage et swap

Un disque neuf traverse toujours la même chaîne : voir, découper, formater, monter, puis rendre permanent. Sauter une étape donne un message d'erreur qui parle d'autre chose.

Du disque neuf au dossier utilisable

1
lsblk  Le disque est-il vu ? Puis sudo fdisk -l /dev/vdb pour la table actuelle.
2
sudo fdisk /dev/vdb  n → p → numéro → Entrée → +8G → p pour vérifier → w pour écrire et quitter.
3
sudo partprobe  si lsblk ne montre pas encore /dev/vdb1
4
sudo mkfs.ext4 /dev/vdb1  la partition, jamais le disque
5
sudo mkdir -p /mnt/ASR-DATA puis sudo mount /dev/vdb1 /mnt/ASR-DATA
6
df -h  la ligne du point de montage prouve que c'est monté. Démonter : cd ~ puis sudo umount /mnt/ASR-DATA — occupé ? sudo lsof /mnt/ASR-DATA

Rendre le montage permanent

sudo cp /etc/fstab /etc/fstab.bak # filet de sécurité, toujours sudo blkid /dev/vdb1 # récupérer l'UUID UUID=d4e19f22-8b7c-… /mnt/ASR-DATA ext4 defaults 0 2 sudo mount -a # tester AVANT de redémarrer

Les six colonnes : périphérique (UUID, jamais /dev/vdb1 qui peut changer d'ordre) · point de montage · type · options · dump · vérification fsck — 0 pour le swap et pour XFS qui ne passe pas par fsck, 1 pour une racine ext4, 2 pour les autres. Une erreur ici peut bloquer le démarrage : d'où mount -a, et journalctl -xe si ça coince.

Swap — deux formes, deux écritures

Partition de swap (type 82)
sudo mkswap /dev/vdc1 sudo swapon /dev/vdc1 free -h # vérifier fstab : UUID=7f1c9e33-… none swap sw 0 0
Fichier de swap
sudo fallocate -l 1G /swapfile sudo chmod 600 /swapfile # critique sudo mkswap /swapfile sudo swapon /swapfile fstab : /swapfile none swap sw 0 0

Une partition se déclare par son UUID, un fichier par son chemin. Redimensionner un fichier : swapoff → rm → fallocate → chmod 600 → mkswap → swapon. Tendance à basculer : sudo sysctl vm.swappiness=10.

Les pièges qui coûtent des points
  • Formater /dev/vdb au lieu de /dev/vdb1 : la table de partitions est détruite.
  • Oublier le w dans fdisk : rien n'est écrit, et lsblk ne montre aucune partition.
  • Écrire ext4 au lieu de swap dans fstab, ou un UUID pour un fichier de swap.
  • Oublier chmod 600 : swapon avertit ou refuse — ce fichier contient des morceaux de mémoire vive.
  • Racine en XFS (le défaut de Rocky 9) : swapon peut refuser un fichier créé par fallocate. On le crée alors avec dd if=/dev/zero of=/swapfile bs=1M count=1024.
