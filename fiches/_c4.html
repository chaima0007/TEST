Disques, montage et swap

Toujours la même chaîne : voir, découper, formater, monter, rendre permanent. Sauter une étape donne une erreur qui parle d'autre chose.

Du disque neuf au dossier utilisable

1
lsblk le disque est-il vu ? · lsblk -f UUID et type
2
sudo fdisk /dev/vdb  n → p → numéro → Entrée → +8G → p pour vérifier → w pour écrire et quitter.
3
sudo partprobe /dev/vdb si lsblk ne montre pas encore /dev/vdb1 · puis sudo mkfs.ext4 /dev/vdb1 la partition, jamais le disque
4
sudo mkdir -p /mnt/ASR-DATA puis sudo mount /dev/vdb1 /mnt/ASR-DATA
5
df -h  la ligne du point de montage prouve que c'est monté. Démonter : cd ~ puis sudo umount /mnt/ASR-DATA — occupé ? sudo lsof

Rendre le montage permanent

sudo cp /etc/fstab /etc/fstab.bak # filet de sécurité, toujours sudo blkid /dev/vdb1 # récupérer l'UUID sudo vi /etc/fstab # y ajouter la ligne : UUID=d4e19f22-8b7c-… /mnt/ASR-DATA ext4 defaults 0 2 sudo systemctl daemon-reload # fstab a changé sudo mount -a # tester AVANT de redémarrer

Six colonnes : périphérique (UUID, jamais /dev/vdb1) · point de montage · type · options · dump · fsck — 0 pour le swap et XFS, 1 pour une racine ext4, 2 sinon. Une erreur ici bloque le démarrage : d'où mount -a avant de redémarrer.

Swap — deux formes, deux écritures

Partition de swap — type 82 (MBR) ou 19 (GPT)
sudo mkswap /dev/vdc1 sudo swapon /dev/vdc1 free -h # vérifier · swapon -s
Fichier de swap
sudo dd if=/dev/zero of=/swapfile \ bs=1M count=1024 # racine XFS sudo chmod 600 /swapfile # critique sudo mkswap /swapfile ; sudo swapon /swapfile

Dans fstab, une partition se déclare par son UUID, un fichier par son chemin :
UUID=7f1c9e33-…  none  swap  sw  0 0   /swapfile  none  swap  sw  0 0
Redimensionner un fichier : swapoff → rm → recréer → chmod 600 → mkswap → swapon. Tendance du noyau à basculer : sudo sysctl vm.swappiness=10, en mémoire seulement — permanent dans /etc/sysctl.d/99-swappiness.conf.

Les pièges qui coûtent des points
  • Formater /dev/vdb au lieu de /dev/vdb1 : la table de partitions est détruite. Oublier le w dans fdisk : rien n'est écrit, et lsblk ne montre aucune partition.
  • Écrire ext4 au lieu de swap dans fstab, ou un UUID pour un fichier de swap. Oublier chmod 600 : swapon avertit ou refuse — ce fichier contient des morceaux de mémoire vive.
  • fallocate -l 1G /swapfile est plus rapide, mais ne convient qu'à ext4 : sur XFS — racine par défaut de Rocky 9 — swapon refuse le fichier.
